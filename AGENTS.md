# Repository instructions

The only production specification is `SYSTEM_PROMPT.md`. Keep it paste-ready,
self-contained, and free of product-interface code.

When updating the workflow:

- Preserve the two-input contract: topic and aspect ratio.
- Preserve the six-person continuous-dialogue relay.
- Keep VideoExpress generator prompts positive and concise.
- Do not add forbidden overlay-removal wording to generator prompts.
- Update `evals/acceptance-checklist.md` when behavior changes.
- Add a representative example to `examples/requests.md` for a new input rule.
